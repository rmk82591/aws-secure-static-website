Secure Static Website on AWS

This page is a portfolio project by RMK. The page itself is simple on purpose. What matters is how it is built and delivered.

  • Files live in a private S3 bucket that nobody can open directly.
  • CloudFront serves them to visitors over HTTPS.
  • The whole setup is written as a CloudFormation template, so it can be deleted and rebuilt.
